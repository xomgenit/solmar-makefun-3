SOLMAR — Streets of the Sun: an original 2D top-down open-world crime game set in Solmar Bay. Danny "Dice" Marlow is back in town — steal cars, outrun the SBPD, and take jobs from fixer Vera Santos while the Harbor Kings close in. A seeded procedural city with 9 named landmarks, arcade driving across 5 car models, a 0–5 wanted system with foot cops and cruiser pursuit, mouse-aim combat, 5 story missions, 3 hidden cash stashes, a sports-car unlock, and a full HUD with a round minimap. Fully offline: no network requests, no external assets, WebAudio-synthesised sound only.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## Controls

WASD move/drive · Mouse aim · Click shoot · E steal/exit car or interact · Shift sprint · Space handbrake · Esc pause · M mute
