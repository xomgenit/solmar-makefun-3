# SOLMAR — Streets of the Sun

An original 2D top-down open-world crime game set in Solmar Bay, built for make.fun's "Make GTA 6" bounty (gta6-01).

Danny "Dice" Marlow is back in town. Steal cars, outrun the SBPD, and take jobs from fixer Vera Santos.

## Run it

```
node serve.ts
```

Then open http://localhost:8080. Fully offline — no network requests, no external assets, WebAudio-synthesised sound only.

## Controls

WASD move/drive · Mouse aim · Click shoot · E steal/exit car · Shift sprint · Space handbrake · Esc pause · M mute
